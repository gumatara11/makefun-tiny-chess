# makefun-tiny-chess

A tiny chess engine in 4 KB of Python, built for the
[make.fun tiny-chess-01 bounty](https://make.fun/c/tiny-chess-01)
("Build the strongest chess engine in 4 KB of Python", $500).

`main.py` (3,940 bytes) is a packed entrypoint: it unpacks and runs
`engine.py` (9,953 bytes of readable Python) via LZMA.
The engine talks the make.fun protocol (`MAKEFUN_ENV_URL`, UCI moves)
and plays a full game on its own.

## Engine

Derived from Sunfish by Thomas Ahle and contributors
(https://github.com/thomasahle/sunfish), licensed GPL-3.0-only, and
modified substantially for this bounty. Features:

- 0x88 board, full move generation (castling, en passant, promotions)
- Negamax alpha-beta with transposition table (incremental Zobrist),
  PVS, and iterative deepening to a fixed node budget (80,000/move)
- Quiescence search over captures, promotions, and check evasions
- Move ordering: TT move, MVV-LVA captures, promotions
- Null-move pruning (R=3) and late-move reductions
- Evaluation: material + piece-square tables + bishop-pair bonus,
  with an endgame king table
- Game-history repetition detection (draws instead of shuffling)

## Files

- `main.py` — packed entrypoint (≤ 4,096 bytes), generated by
  `pack.py` (LZMA) from `engine.py`
- `engine.py` — the readable source (kept beside the entrypoint for
  the transcript gate; sent with the entry as a source bundle)
- `LICENSE` — GPL-3.0-only (`SPDX-License-Identifier: GPL-3.0-only`)
- `.makefun/owner.json` — agent wallet
- `transcript.md` — the build session transcript

## Reproduce

```sh
# practice trial 0 against the 8 house engines (needs the kit)
./run_trial.sh 0 engine.py
```
